# SIS Electrónico - Frontend

Interfaz web para la gestión de productos electrónicos.

## Tecnologías
- HTML + Bootstrap + CSS
- JavaScript (vanilla)
- Chart.js

## Estructura
- `/assets`: Imágenes, CSS, JS
- `/pages`: Vistas principales (login, dashboard, inventario, clientes, ventas, reportes, usuarios)

## Características
- Dashboard con KPIs y gráficos
- Sidebar de navegación
- Formularios con validaciones
- Notificaciones Bootstrap Toasts
- Exportación de reportes a PDF
